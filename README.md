Завдання 1: Enum і базова модель
Опишіть рядковий enum ItemStatus зі значеннями: доступно, видано, втрачено.
Опишіть інтерфейс LibraryItemData:
id — число

title — рядок

year — число

status — ItemStatus

internalNote — рядок (це для працівників, назовні не віддаємо)

У ANSWERS.md напишіть одним реченням, чому тут рядковий enum, а не числовий.

Завдання 2: Три похідні типи
Виведіть із LibraryItemData три типи, не переписуючи поля руками:

PublicItem - усе, крім internalNote
ItemPreview - тільки id і title
ItemUpdate - усі поля необов'язкові, і без id
Створіть по одній змінній кожного типу, щоб перевірити, що працює.

Підказка до третього: утиліти можна вкладати одна в одну.
Завдання 3 : Абстрактний клас
Опишіть абстрактний клас LibraryItem:

конструктор приймає title і year, обидва зберігає як protected
приватне поле #status зі значенням «доступно» за замовчуванням
гетер status, який його повертає
метод borrow() - змінює статус на «видано»; якщо предмет уже видано, друкує повідомлення і нічого не змінює
абстрактний метод describe(): string - без тіла
Завдання 4: Два нащадки
Створіть Book і Magazine, які успадковують LibraryItem.

Book додатково приймає author, describe() повертає щось на кшталт "Книга: {title} ({year}), автор {author}"
Magazine додатково приймає issueNumber, describe() повертає "Журнал: {title}, випуск №{issueNumber}"
Обидва мусять викликати super() у конструкторі.

Закоментованим рядком покажіть спробу написати new LibraryItem(...) і текст помилки, яку показує компілятор.

Завдання 5: implements
Опишіть інтерфейс Searchable з одним методом matches(query: string): boolean.

Зробіть так, щоб Book його реалізовував: метод повертає true, якщо query міститься в назві або в імені автора (без урахування регістру).

У ANSWERS.md: чи запрацював би цей код, якби ви не написали слово implements? Чому?

Завдання 6: Поліморфізм
Створіть масив типу LibraryItem[] із двох книг і одного журналу.

Пройдіться по ньому в циклі й для кожного елемента виведіть результат describe().

Умова: у вашому циклі не повинно бути жодного if про тип елемента і жодного instanceof.
