Homework 18 "Робота з MongoDB (поглиблення)"

Завдання 1: Розширення бази shopDB
У базі shopDB створи нову колекцію users.
Додай вручну 5 користувачів у форматі JSON:
json

Copy code
{
"name": "Olena",
"email": "olena@example.com",
"age": 28,
"city": "Kraków",
"isActive": true
}
Користувачі мають бути з різними значеннями age, city та isActive (частина true, частина false).

Формат здачі: скріншот колекції users у Compass.

Завдання 2: Наповнення колекції products
Додай ще 7 товарів у колекцію products, щоб було різноманіття для запитів:

різні категорії (electronics, books, clothing, food)
різний price (від дешевих до дорогих)
різний stock (частина товарів з stock: 0)
Завдання 3: Запити на пошук (find)
Виконай наступні запити у вкладці Filter у Compass (або в mongosh) і збережи результат кожного скріншотом:

Знайти всі товари категорії electronics
Знайти товари, у яких price більше 500
Знайти товари, яких немає в наявності (stock: 0)
Знайти товари з ціною в діапазоні від 100 до 1000
Знайти всіх активних користувачів (isActive: true)
Знайти користувачів, старших за 25 років
💡 Підказка — оператори порівняння: $gt, $gte, $lt, $lte, $eq, $ne.

Приклад фільтра:

json

Copy code
{ "price": { "$gt": 500 } }
Завдання 4: Сортування та обмеження
Виведи всі товари, відсортовані за price від дорогих до дешевих.
Виведи 3 найдешевші товари.
Виведи користувачів, відсортованих за age за зростанням.
💡 У Compass використовуй поля Sort (напр. { "price": -1 }) та Limit.

Завдання 5: Оновлення та видалення (вручну в Compass)
Онови stock будь-якого товару через кнопку редагування документа.
Додай нове поле discount (напр. 10) до одного з товарів.
Видали один товар з колекції.
Формат здачі: скріншоти до та після кожної операції.

Додаткове (за бажанням)
Спробуй виконати запит із кількома умовами одночасно — наприклад, знайти товари категорії electronics, у яких price менше 1000 і stock більше 0:

json

Copy code
{
"category": "electronics",
"price": { "$lt": 1000 },
"stock": { "$gt": 0 }
}
