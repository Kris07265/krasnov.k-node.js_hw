Завдання 1: Опишіть свій перший інтерфейс
Оголосіть інтерфейс Book, який описує книжку та має такі поля:

title — рядок
author — рядок
year — число
pages — число
Створіть одну змінну типу Book і заповніть її реальними даними про будь-яку книжку. Виведіть у консоль назву та автора у форматі "Назва" — Автор.

Очікуваний результат: у консолі рядок типу "1984" — George Orwell.

Перевірте себе: приберіть у своєму об'єкті поле year. Що скаже компілятор при tsc hw.ts? Поверніть поле назад.

Завдання 2: Опціональні поля
Додайте до інтерфейсу Book ще два поля:

genre — рядок, опціональне (може бути, а може й ні)
rating — число, опціональне
Створіть дві книжки: одну з усіма полями, включно з genre та rating, а другу — тільки з обов'язковими полями.

Напишіть функцію printBook(book: Book), яка виводить назву й автора завжди, а жанр і рейтинг — тільки якщо вони є (використайте перевірку if).

Очікуваний результат: для першої книжки виводяться всі дані, для другої — тільки назва й автор, без помилок.

Щ1\о станеться, якщо звернутися до book.rating без перевірки на існування? Спробуйте.

Завдання 3: readonly — захист від змін
Додайте до інтерфейсу Book поле:

id — число, позначене як readonly
Створіть книжку з id. Потім спробуйте у наступному рядку змінити цей id (наприклад, myBook.id = 99).

Очікуваний результат: компілятор tsc hw.ts має видати помилку про те, що readonly-властивість не можна змінювати. Прочитайте текст помилки уважно.

Після того як переконалися, що помилка з'являється, закоментуйте рядок зі зміною id, щоб код компілювався.

Перевірте себе: чому readonly корисний саме для поля id, а не, скажімо, для rating?

Завдання 4: Масив об'єктів та функція з інтерфейсом
Створіть масив library з щонайменше чотирьох книжок (тип масиву — Book[]).

Напишіть функцію getRecentBooks(books: Book[], afterYear: number): string[], яка повертає масив назв книжок, виданих пізніше за вказаний рік.

Викличте функцію для року 2000 і виведіть результат у консоль.

Очікуваний результат: масив рядків — назви книжок, виданих після 2000 року. Наприклад: ["Book A", "Book C"].

Підказка: згадайте .filter() та .map() — саме так ми робили в прикладі student.ts на уроці.
